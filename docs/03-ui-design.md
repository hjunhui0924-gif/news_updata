# 界面设计规范 · 知更

更新日期：2026-09-13。采用浅色阅读器风格，目标是快速扫描变化、读懂中文内容、随时核对来源。

## 视觉方向

灰白底色、深色正文、蓝色强调，规整列表与克制的边框。品牌为「知更 / NEWSROOM」，装饰服务于阅读，不引入大图封面或聊天窗。系统中文字体，无须加载外部字体。

| 内容面板 | #FFFFFF |

颜色和响应式细节以 `src/app/globals.css` 为准。保持适量留白，正文使用舒适行高，状态同时使用文字与图标。

## 页面与布局

| 路径           | 内容                                  |
| -------------- | ------------------------------------- |
| /today         | GitHub Trending 热门发现与语言榜单            |
| /feed          | 全部更新、搜索、类型/来源/未读筛选    |
| /saved         | 收藏                                  |
| /items/[id]    | 可直接打开的详情，不存在时显示 404    |
| /subscriptions | 仓库/作者、重点、暂停、同步进度、删除 |
| /onboarding    | 订阅管理与添加弹窗                    |
| /settings      | 时区、紧凑列表、服务状态、站内简报    |
| /login         | 真实模式的 GitHub 登录入口            |

桌面从左到右为导航、更新列表、内容详情。1280px 以上侧栏约 224px，列表约 435px；超宽屏列表适度扩展。768～1279px 保留侧栏，列表与详情互相切换。小于 768px 使用单列与底部五项导航（精选、更新、收藏、订阅、设置）。

详情保留返回列表入口，地址随选择更新。390、768、1440px 已进行浏览器检查；长代码和表格在内容内部滚动，不撑宽整页。

## 核心交互

- 首次展示 20 条，点击加载更多；搜索覆盖当前加载到客户端的所有个人条目。
- 列表区分选中、未读与收藏；详情显示后通过接口保存已读。
- 收藏等待持久化成功后显示新状态，失败提示原因。
- 中文摘要展示概览、最多三条变化、影响与兼容性，可展开查看原文片段依据。
- 译文按需生成，重复访问复用结果；原文标签始终独立可用。
- 添加订阅使用 Radix 弹窗，支持键盘焦点管理、Esc 关闭；导入显示部分成功和截断提示。
- 更新通知在顶部铃铛入口显示，简报在设置页阅读，没有邮件启用流程。

## 状态与可访问性

演示样本、历史补查、AI 未启用/失败/处理中、来源限流、覆盖不完整和 Worker 离线使用明确文字。列表没有匹配项时提供清空筛选；没有精选不等于没有任何更新。

订阅管理按加入本应用的时间倒序展示，最新订阅在前，同一时间以 ID 保持稳定。暂停、重点标记和同步不改变顺序；此时间不等于历史 GitHub Star 时间。真实 AI 关闭时，详情明确说明摘要/翻译未启用并禁用生成按钮；已有结果及原文仍可阅读。AI 启用后，历史未生成条目可手动生成，译文按需生成并保存。

图标按钮有可访问名称，焦点样式可见，标签页和开关使用语义角色，过渡尊重 reduced-motion。当前是基本可访问交互与响应式测试，尚未进行完整屏幕阅读器审计。

## 借鉴范围

前期方案参考 Folo 的多来源阅读结构、NewReleases 的版本订阅、Readwise Reader 的阅读与收藏流程，以及 Inoreader 的过滤组织。借鉴的是任务结构和交互，不复制其品牌素材或源码；官网介绍和公开反馈不能视为完整产品实测或效果排名。

当前风格是可调整的第一版。后续根据实际内容量与用户反馈，再决定深色模式、快捷键、摘要密度和移动端细节。
