用户已明确取消邮件，P4 从初稿的 SMTP 通知改为纯网页简报，移除 Mailpit 和邮件依赖。当前 Docker 仅承载 PostgreSQL。

## 本地 MVP 与后续阶段

Star 增量模块已补充手动分页导入与当前账号自动发现：先完成数据库、调度和 10 项集成测试，再实现网页控制和浏览器回归。每 5 分钟发现新增公开 Star；详细范围与验证记录见 [Star 跟踪](08-starred-tracking.md)。

本地 MVP 不依赖真实 OAuth/LLM 凭据即可体验，演示内容有明确标识。真实 GitHub 公开更新可立即添加；配置模型后真实内容才能生成 AI 摘要/译文。

后续按依赖顺序推进：

1. 使用实际关注对象、GitHub OAuth App 和选定的模型服务，完成端到端登录及真实中文质量评估。
2. 连续试用，记录漏抓、重复、延迟、错误率和费用；这一步需要真实时间，不用单次测试替代。
3. 补齐 ETag、服务端分页、following 多页导入、长文分段翻译和账号改名迁移。
4. 在用户选定主机后配置 HTTPS、进程守护、数据库备份恢复和生产监控。
5. 评估 RSS 或 X 官方接口条件，再增加来源平台字段和独立适配器。

每个后续模块仍执行实现、测试、审查的闭环。暂不实现邮件、公开注册或收费体系。
