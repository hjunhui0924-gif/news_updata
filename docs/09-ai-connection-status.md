# 订阅排序与真实 AI 联调

日期：2026-09-13。

## 已交付

- 订阅列表按 `createdAt` 转为时间戳后倒序排列，同时间按 ID 倒序，状态变化不再导致列表顺序不稳定。该字段是加入应用的时间，不是 GitHub 原始 Star 时间。
- 详情使用当前服务开关显示摘要/翻译状态，关闭时禁止提交真实生成请求，但已有结果和演示流程仍可读。开关恢复后，即使历史条目的 `aiStatus` 仍是 `disabled`，也可手动生成。
- 模型接口将免费额度耗尽、授权失败和请求受限转换为中文提示，不向用户返回供应商原始错误正文或凭据。

## 真实验证与阻碍

当前配置为百炼兼容接口、`qwen3.7-flash`。密钥已存在，`LLM_ENABLED=false`，输入/输出单价仍为 0。对真实更新提交摘要请求，复现「尚未配置 AI 服务」；真实小请求进一步返回 HTTP 403，错误码 `AllocationQuota.FreeTierOnly`，含义是免费额度已耗尽，账号限制为仅用免费额度。

严格结构化请求和 JSON object 的小探测请求都被额度限制拒绝，未返回任何摘要、译文或 usage；因此不能声称模型格式兼容性、真实生成质量或价格已经验证。未修改供应商付费设置、切换模型、启用自动调用或将模拟结果写入真实内容。

继续条件：用户在百炼控制台恢复可用额度，或指定有额度的模型。随后核对实际 token 单价，完成一条真实摘要及译文的验证，再开启应用 AI，并补生成已获取更新的摘要。全文翻译保留按需生成。官方文档网页读取本轮超时，未将猜测价格写入配置。

## 验证

- `pnpm test`：11 个文件，71 项通过，包括订阅时间排序与状态更新不改变顺序、5 项模型错误处理回归。
- `pnpm test:e2e:ai`：1 项通过，覆盖真实条目服务关闭、恢复开关后历史条目可生成、额度错误可见、关闭服务后已有结果仍可读，未出现页面脚本异常。
- 浏览器使用本机 Chrome，3002 端口的隔离 demo 实例；模型状态和响应为可控模拟，不代表真实 AI 已恢复。
