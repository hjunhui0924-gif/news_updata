## 切换前的阻碍

切换前配置为百炼兼容接口、`qwen3.7-flash`，`LLM_ENABLED=false`，输入/输出单价为 0。对真实更新提交摘要请求，复现「尚未配置 AI 服务」；真实小请求进一步返回 HTTP 403，错误码 `AllocationQuota.FreeTierOnly`，含义是免费额度已耗尽，账号限制为仅用免费额度。

严格结构化请求和 JSON object 的小探测请求都被额度限制拒绝，未返回任何摘要、译文或 usage；因此不能声称模型格式兼容性、真实生成质量或价格已经验证。未修改供应商付费设置、切换模型、启用自动调用或将模拟结果写入真实内容。

## 真实调用推动的修复

最初真实输出曾出现英文概览、只翻标题及段落合并，这些不能仅依赖 JSON Schema 判定质量。摘要提示明确要求中文，校验非空说明字段包含中文；译文改为逐段 `{id,text}` 结构，核对编号完整性、唯一性和逐段中文输出后，由应用恢复标题、列表、空行、硬换行与代码围栏。明显缩短或遗漏列表的结果不会保存。中文字符与长度检查属于保守的失败检测，不能证明语义完全正确。

提示/输出合约及思考参数纳入缓存键，旧版生成结果不用于新版缓存。真实联调期间的失败记录保留；所有缺失摘要最终已补齐。临时补生成消费者已停止，保留常驻 Web 和 Worker。
