# 工作空间首页、账号菜单与个人 AI

日期：2026-11-05。本轮按用户确认实现首页引导和统一个人入口，沿用现有 React / Next.js、语义 CSS 与组件。

## 页面与操作

- `/` 与登录成功后进入 `/home`。首页展示登录、添加来源、首次同步、开始阅读四步引导，以及平台连接、来源数量、未读和 Worker 状态。原 `/today` 今日精选仍保留在“更多工具”。
- 点击侧栏底部账号弹出菜单，提供工作空间首页、阅读偏好、账号与连接、个人 AI 服务、使用帮助和真实模式退出登录。支持方向键、Home / End、Esc、点击外部关闭；手机从顶部导航抽屉进入。
- 未保存配置或请求处理期间，站内跳转、浏览器后退 / 前进和退出均先确认；取消时保留草稿。退出取消不发送结束会话请求，确认退出成功后不重复询问。手机按 Esc 先关闭账号小窗，继续保留导航抽屉。
- `/settings` 保留阅读偏好；`/connections` 集中账号状态和授权 / 导入入口；`/ai-settings` 提供可选个人模型；`/help` 解释授权、导入、同步与费用。相关页面使用统一设置导航，不继续增加常驻侧栏分组。

## 个人模型服务

用户在“账号菜单 → 个人 AI 服务”选择站点 AI、个人模型或停用。个人模式填写管理员允许的服务地址、模型标识、自己的 API Key、实际输入 / 输出美元单价和日 / 月预算，保存后再测试。测试会产生一次小额请求，只说明基础接口可用，不保证所有长文和结构化输出场景都成功。

API Key 使用服务端认证密钥加密保存，不回显、不写入 localStorage 或 sessionStorage。留空保留已存密钥，更换服务地址必须重新填写密钥。停用和站点模式不能通过隐藏字段修改保留密钥的服务地址。删除需要确认，删除后停用 AI，不自动改为站点付费。

Web 和 Worker 都按任务所属用户解析配置；摘要、正文 / 简介翻译、Trending 简介翻译和 Skill AI 使用同一解析逻辑。个人与站点费用分开预占和结算，个人不占用站点模型预算；个人预算按 UTC 日 / 月统计、在数据库中原子检查。未知是否计费的超时保留预占，不把供应商错误正文直接展示给用户。

缓存按用户隔离个人结果，继续包含模型、服务地址、提示词与原文版本。仅更改预算、价格或停用后恢复同一服务，不会作废已有结果；读取历史结果也不会自动发起付费请求。配置保存采用版本检查，旧表单不能覆盖另一标签页的更新。连接测试的版本校验和密钥解析来自同一数据库快照。

已经发给供应商的请求无法通过本地删除撤回，仍可能完成或计费；页面有明确说明。应用预算是估算，不替代供应商硬额度。普通用户无需填写 GitHub / Google OAuth 客户端密钥。

## 管理员启用与迁移

新增 `drizzle/0008_personal_ai.sql`：`personal_ai_settings` 按用户保存模式、并发版本、密文和非秘密配置；`ai_usage.billing_scope` 对既有数据默认回填为 `site`。升级前按现有上线流程备份，再执行迁移；Web / Worker 必须使用相同的认证密钥。

个人服务默认关闭。管理员在 `.env.local` 或 `deploy/server.env` 配置 `LLM_PERSONAL_ALLOWED_BASE_URLS`，使用逗号分隔的、可信且完整的 HTTPS 模型 API 基地址，然后重启 / 重建 Web 和 Worker 的运行配置。只填到 API 基地址，不包含 `/chat/completions`，不要在 URL 中放令牌或查询参数。生产 Compose 已传递该配置。

服务地址必须精确匹配允许项；普通用户不能让服务器访问任意地址。只允许无凭据、查询参数和自定义端口的 HTTPS 域名，不接受本机或 IP 地址，模型请求不跟随重定向。允许名单只应加入可信模型服务，不应加入用户控制或解析到内部网络的域名。

Demo 只展示配置状态，拒绝保存真实个人密钥和模型调用。开发及浏览器测试使用独立数据库、合成密钥和模拟模型响应，不触碰真实平台账号。
